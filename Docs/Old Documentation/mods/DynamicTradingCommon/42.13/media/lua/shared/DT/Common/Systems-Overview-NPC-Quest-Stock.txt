Title: NPC Roster Quest and Stock Systems Overview
Tags: [npc, roster, souls, quest, stock, wardrobe, traders, restock]

Consolidated overview of NPC/Roster management, Quest item system, and Stock management. Covers soul registry, trader tracking, NPC wardrobe, quest packages, and inventory restocking.

## NPC/Roster System

**Files:** @DT_NPC_Archetypes.lua, @DT_NPC_Wardrobe.lua, @DynamicTrading_Roster.lua

### Soul Registry

Persistent NPC identities stored in `DynamicTrading_Roster.Souls[uuid]`:

```lua
{
    uuid = unique_id,                   -- Generated on creation
    name = "John Smith",                -- Display name
    isFemale = boolean,                 -- Gender
    archetypeID = "Farmer",             -- Trader type
    factionID = "Rosewood_12345",       -- Parent faction
    status = "Trading"|"Dead"|"Roaming", -- Current state
    portraitID = number,                -- Portrait index (0-99)
    inventoryDef = {...},               -- Clothing outfit array
    homeCoords = {x, y, z},             -- Spawn location
    memory = {                          -- Player interactions
        [username] = {
            trust = 50,
            lastSeen = hour,
            tradeVolume = 10000
        }
    }
}
```

**Key Functions:**
- `AddSoul(factionID, archetypeID, homeCoords)` - Creates new soul
- `RemoveSoul(factionID, count)` - Removes N random souls
- `GetSouls(factionID)` - Returns array of UUIDs in faction
- `GetSoulRegistry(uuid)` - Returns full soul data
- `ClearSouls(factionID)` - Removes all souls from faction

**Status Types:**
- **Trading:** Active trader, appears in roster syncs
- **Dead:** Killed, excluded from rosters
- **Roaming:** Temporarily away, excluded from rosters

**Persistence:** ModData `"DynamicTrading_Roster"`

### NPC Wardrobe

**40+ Archetypes** with gender-specific outfit combinations.

**Data Structure:**
```lua
DT_NPC_Wardrobe[archetypeID] = {
    Male = {
        { "Base.Hat_Cowboy", "Base.Shirt_Farmer", "Base.Trousers_Denim" },
        { "Base.Hat_BaseballCap", "Base.Tshirt_White", "Base.Jeans" },
        { outfit3... }
    },
    Female = {
        { "Base.Hat_SunHat", "Base.Dress_Short", "Base.Shoes_FlipFlop" },
        { outfit2... },
        { outfit3... }
    }
}
```

**Purpose:**
- Prevents NPCs spawning naked
- Provides archetype-appropriate clothing
- Random variety (3-5 outfits per archetype/gender)

**Examples:**
- **Farmer:** Cowboy hat, flannel shirt, denim, work boots
- **Doctor:** Lab coat, mask, scrubs, gloves
- **Mechanic:** Cap, coveralls, work boots, gloves
- **Sheriff:** Police uniform, hat, utility belt

**Usage:**
```lua
local outfit = DT_NPC_Wardrobe["Farmer"]["Male"][1]
-- outfit = { "Base.Hat_Cowboy", "Base.Shirt_Farmer", "Base.Trousers_Denim" }
```

## Quest System

**Files:** @DT_QuestManager.lua, @DT_QuestItems.lua

### Quest Package Items

**7 Package Types:**
- Small Food
- Medium Food
- Large Hardware
- Medium Military
- Fragile (Glass/Electronics)
- Medical Parcel
- Gift Box

**Item Creation:**
```lua
DynamicTrading.Quest.SpawnQuestItem(player, packageType, difficulty)
```

**Process:**
1. Select appropriate quest item texture
2. Calculate weight based on difficulty:
   ```lua
   baseWeight = {
       Small = 2.0,
       Medium = 5.0,
       Large = 10.0,
       Fragile = 3.0
   }
   finalWeight = baseWeight × difficulty
   ```
3. Generate unique QuestID
4. Set custom name: "Package for [Name]"
5. Set tooltip with quest details
6. Store ModData:
   ```lua
   {
       QuestID = unique_id,
       Timestamp = gameHour,
       IsQuestItem = true,
       BaseWeight = weight
   }
   ```
7. Apply weight reduction (30% when spawned/on ground)

**Weight Mechanics:**
- **In inventory:** Full weight (difficulty scaled)
- **On ground:** 70% weight (30% reduction)
- **Just spawned:** 70% weight (encourages pickup)

**Inventory Scanning:**
```lua
DynamicTrading.Quest.FindQuestItems(player)
  → Recursive container search
  → Returns array of quest item objects
```

**Verified Textures:**
- `Parcel_Small_Food`
- `Parcel_Medium_Food`
- `Parcel_Large_Hardware`
- `Parcel_Medium_Military`
- `GenericMedicalParcel1`
- `Present4`

**Network Support:**
```lua
-- Singleplayer
DynamicTrading.Quest.SpawnQuestItem(player, "Medium", 1.5)

-- Multiplayer
sendClientCommand("DT_Quest", "SpawnQuestItem", {
    packageType = "Medium",
    difficulty = 1.5
})
```

## Stock Management System

**File:** @DynamicTrading_Stock.lua

### Stock Data Structure

```lua
DynamicTrading_Stock[traderID] = {
    items = {
        [itemFullType] = {
            qty = number,
            basePrice = number,           -- Original base price
            dynamicMod = number,          -- Scarcity multiplier
            customData = {                -- Condition data
                usedDelta = 0.8,
                fluidAmount = 7.5,
                condition = 85,
                hungerChange = -0.12
            }
        }
    },
    restock = {
        lastRestockTime = hour,
        nextRestockTime = hour + interval
    },
    factionID = factionID,
    name = traderName,
    archetype = archetypeID,
    portraitID = number,
    gender = "Male"|"Female"
}
```

**Persistence:** ModData `"DynamicTrading_Stock"`

---

### Stock Operations

**Initialize Inventory:**
```lua
DynamicTrading_Stock.InitializeInventory(traderID, initialItems)
  - Creates new stock entry
  - Sets restock timers
  - Populates items table
```

**Update Quantity:**
```lua
DynamicTrading_Stock.UpdateItemQty(traderUUID, itemFullType, delta, playerObj)
  - Adjusts item quantity (+ for add, - for remove)
  - Triggers faction wealth changes on trades
  - Updates dynamic scarcity modifier
  - Syncs to clients
```

**Scarcity System:**
- `qty == 0` → `dynamicMod = 1.5` (50% price increase)
- `qty < 5` → `dynamicMod = 1.2` (20% price increase)
- `qty >= 5` → `dynamicMod = 1.0` (normal price)

**Purpose:** Creates supply/demand dynamics

---

### Restock System

**Default Interval:** 24 hours (configurable)

**Process:**
1. Check if `currentTime >= nextRestockTime`
2. If yes:
   - Call `GenerateStock()` with archetype
   - Replace entire inventory
   - Update `lastRestockTime = currentTime`
   - Set `nextRestockTime = currentTime + interval`
   - Transmit to clients

**Manual Restock (Admin):**
```lua
DynamicTrading_Stock.ForceRestock(traderID)
  - Immediately regenerates stock
  - Resets timers
```

**Configuration:**
```lua
SandboxVars.DynamicTrading = {
    RestockInterval = 24,      -- Hours between restocks (1-168)
    RestockOnTrade = false     -- If true, restocks after each trade
}
```

---

### Stock Generation Integration

Uses @DT_Economy_Common.lua GenerateStock():

**Inputs:**
- Trader archetype (allocations, forbid, expertTags)
- Difficulty settings (stockMult, rarityBonus)
- Global modifiers (events, heat)

**Outputs:**
```lua
{
    ["Base.Apple"] = {
        qty = 10,
        customData = { hungerChange = -0.15 }
    },
    ["Base.GasCan"] = {
        qty = 2,
        customData = { fluidAmount = 8.5, fluidType = "Petrol" }
    }
}
```

**Storage:**
Stock data stored with basePrice and dynamicMod calculated on access.

## Integration Patterns

### Creating New Trader

```lua
-- 1. Create soul in roster
local uuid = DynamicTrading_Roster.AddSoul(
    "Rosewood_12345",
    "Farmer",
    { x=10950, y=9850, z=0 }
)

-- 2. Generate initial stock
local archetype = DynamicTrading.Archetypes["Farmer"]
local stock = DT_Economy_Common.GenerateStock(
    archetype,
    DynamicTrading.Config.MasterList,
    { stockMult=1.0, rarityBonus=0 },
    {}
)

-- 3. Initialize inventory
DynamicTrading_Stock.InitializeInventory(uuid, stock)

-- 4. Set trader status
local soul = DynamicTrading_Roster.GetSoulRegistry(uuid)
soul.status = "Trading"
```

---

### Quest Item Delivery

```lua
-- 1. Find quest items in player inventory
local questItems = DynamicTrading.Quest.FindQuestItems(player)

-- 2. Validate delivery
for _, item in ipairs(questItems) do
    local modData = item:getModData()
    if modData.QuestID == targetQuestID then
        -- Reward player
        player:getInventory():Remove(item)
        -- Grant currency/rep
    end
end
```

### Stock Monitoring

```lua
-- Check stock levels
local stock = DynamicTrading_Stock[traderUUID]
for itemKey, itemData in pairs(stock.items) do
    if itemData.qty < 3 then
        print("Low stock: " .. itemKey .. " (" .. itemData.qty .. ")")
    end
end

-- Check restock timer
local hoursUntilRestock = (stock.restock.nextRestockTime - currentHour)
print("Restock in " .. hoursUntilRestock .. " hours")
```

## Performance Considerations

**NPC/Roster:**
- Lazy loading of soul "brain" data (not all loaded at once)
- Roster filtering excludes non-Trading status (50-70% reduction)
- Batch soul removal (RemoveSoul(N) not N × RemoveSoul(1))

**Quest:**
- Recursive search cached per trade UI open
- Weight reduction reduces inventory calculations
- Quest tag (weight=0) prevents accidental spawning

**Stock:**
- Items stored as tables (fast lookup)
- Scarcity mods pre-calculated on qty change
- Restock batch operation (not item-by-item)

## Best Practices

1. **Always set soul status** - Affects network sync filtering
2. **Use ForceRestock sparingly** - Can disrupt player economy strategy
3. **Match wardrobe to archetype** - Maintains immersion
4. **Quest items need tags** - Use "Quest" tag (weight=0)
5. **Stock depleted handling** - Show "Out of Stock" UI, don't hide item
6. **Restock notifications** - Inform players when stock refreshes
7. **Soul cleanup on faction death** - Call ClearSouls(factionID)
