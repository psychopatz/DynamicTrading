Title: Tags - Tag Registry with Price and Weight Modifiers
Tags: [tags, registry, pricing, rarity, categories, spawning]

Comprehensive tag registry system that controls item pricing and spawn weights. Defines rarity tiers, item categories, quality modifiers, and conditional/seasonal tags.

## Purpose

Centralizes tag definitions for the entire trading system. Tags affect:
- **Item pricing** (priceMult modifier)
- **Spawn likelihood** (weight for random selection)
- **Archetype targeting** (items matched by tag)
- **Event interactions** (events modify tag prices)

## Tag Structure

Each tag registered with two key properties:

```lua
DynamicTrading.RegisterTag("TagName", {
    priceMult = 1.0,  -- Price multiplier (0.1-10.0+)
    weight = 50       -- Spawn weight (0-100)
})
```

### Price Multiplier (priceMult)

Modifies item base price when calculating final cost:
- `1.0` = No change (baseline)
- `0.5` = 50% cheaper (waste items)
- `1.5` = 50% more expensive (medical supplies)
- `5.0` = 5x more expensive (legendary items)

**Stacking:** Items with multiple tags multiply all priceMult values together.

Example:
```
Item: "GoldWatch"
Tags: ["Misc.Cosmetic", "Legendary"]
Base Price: 100
Final Price: 100 × 3.0 (Cosmetic) × 5.0 (Legendary) = 1500
```

### Spawn Weight

Controls likelihood of appearing in random item pools:
- `100` = Very common (always considered)
- `50` = Medium (baseline)
- `10` = Rare (10% as likely as common)
- `1` = Extremely rare (1% as likely as common)
- `0` = **NEVER spawns randomly** (event/conditional only)

**Usage:** When generating stock, system builds weighted pool. Higher weight = higher chance.

## Rarity Tiers

Global rarity system affecting both price and availability:

### Common (Baseline)
```lua
DynamicTrading.RegisterTag("Common", {
    priceMult = 1.0,
    weight = 100
})
```
- **Standard items** - Canned food, basic tools, common clothing
- **Always available** in appropriate trader stocks


## Tag Hierarchy Convention

Uses dot notation for categorization:

**Format:** `Category.SubCategory.Detail`

**Examples:**
- `Food.Fresh.Meat`
- `Weapon.Firearm.Rifle`
- `Medical.Supply.Bandage`
- `Resource.Material.Wood`
- `Clothing.Head.Hat`

**Benefits:**
- Clear item classification
- Flexible archetype targeting (can target broad or specific)
- Event modifications can affect entire categories

## Tag Stacking Rules

Items can have multiple tags. **All priceMult values multiply together:**

**Example 1: Common Medical Supply**
```lua
item = {
    tags = { "Medical", "Common" },
    basePrice = 20
}
-- Final multiplier: 1.5 (Medical) × 1.0 (Common) = 1.5
-- Final price: 20 × 1.5 = 30
```

**Example 2: Rare Luxury Item**
```lua
item = {
    tags = { "Misc.Cosmetic", "Rare" },
    basePrice = 50
}
-- Final multiplier: 3.0 (Cosmetic) × 2.0 (Rare) = 6.0
-- Final price: 50 × 6.0 = 300
```

**Example 3: Legendary Weapon**
```lua
item = {
    tags = { "Weapon", "Ammo", "Legendary" },
    basePrice = 100
}
-- Final multiplier: 1.3 (Weapon) × 2.0 (Ammo) × 5.0 (Legendary) = 13.0
-- Final price: 100 × 13.0 = 1300
```

## Weight Selection Algorithm

When generating stock with tag `"Food"`:

1. **Collect all items** with "Food" tag
2. **Build weighted pool:**
   - Apple (Common, weight 100) → 100 tickets
   - Caviar (Rare, weight 10) → 10 tickets
   - Stale Bread (Waste, weight 100) → 100 tickets
3. **Random selection** from total tickets (210 total)
   - 100/210 chance = Apple
   - 10/210 chance = Caviar
   - 100/210 chance = Stale Bread

**Result:** Common items appear ~10x more often than rare items.

## Integration with Systems

### Archetype Allocations

Archetypes use tags to define stock:

```lua
allocations = {
    { tags = {"Food", "Drink"}, count = 10 }  -- ANY item with Food OR Drink tag
}
```

### Event System

Events modify tag prices:

```lua
eventData = {
    priceModifier = {
        ["Food"] = 1.5,      -- All food 50% more expensive
        ["Medical"] = 2.0    -- All medical doubles in price
    }
}
```

### Economy Math

@DT_Economy_Common.lua applies tag multipliers:

```lua
local finalPrice = basePrice
for _, tag in ipairs(item.tags) do
    local tagData = DynamicTrading.Config.Tags[tag]
    if tagData then
        finalPrice = finalPrice * tagData.priceMult
    end
end
```

## Adding Custom Tags

```lua
-- Step 1: Register the tag
DynamicTrading.RegisterTag("Custom.MyCategory", {
    priceMult = 1.3,
    weight = 40
})

-- Step 2: Assign to items
DynamicTrading.AddItem("MyMod.CustomItem", {
    tags = { "Custom.MyCategory", "Uncommon" },
    basePrice = 50
})

-- Step 3: Use in archetype
DynamicTrading.RegisterArchetype("CustomTrader", {
    allocations = {
        { tags = {"Custom.MyCategory"}, count = 5 }
    }
})
```

## Best Practices

1. **Use existing tags first** - Don't create new tags unnecessarily
2. **Follow hierarchy convention** - Use dot notation (Category.SubCategory)
3. **Stack tags logically** - Combine rarity + category + quality
4. **Set weight 0 for conditional** - Prevents unwanted random spawns
5. **Test multiplier stacking** - Ensure pricing isn't absurd
6. **Document custom tags** - If adding new categories, explain purpose
7. **Consider event interaction** - Events may modify your tag prices
