Title: Faction System - Lifecycle and Daily Simulation
Tags: [factions, lifecycle, simulation, production, consumption, death, growth, roster]

Persistent faction management system with daily production/consumption cycles, casualties, recruitment, and dynamic town population. Handles faction creation, roster generation, resource tracking, and state transitions.

## Purpose

Creates self-sustaining faction economies that evolve over time. Factions produce resources based on member composition, consume food/meds daily, suffer casualties from events, recruit new members when prosperous, and die out when resources depleted.

## Core Data Structure

```lua
DynamicTrading_Factions[factionID] = {
    id = string,                    -- Unique faction ID
    name = string,                  -- Display name ("The Iron Vanguard")
    town = string,                  -- Town name (Rosewood, Muldraugh, etc.)
    homeCoords = table,             -- { x, y, z, name="Rosewood Fire Station" } or nil (nomadic)
    stockpile = table,              -- { food=200, ammo=100, meds=50, fuel=25 }
    state = string,                 -- "Stable" | "Vulnerable" | "Starving"
    memberCount = number,           -- Total faction members (alive)
    wealth = number,                -- Faction cash reserves
    reputation = table,             -- { [username] = trustLevel }
    starvationDays = number,        -- Consecutive days without food
    consecutiveStableDays = number, -- Days in stable state (for triggers)
    ActiveFlashEvent = table        -- { id=eventID, expires=hour, targetCasualties=N }
}
```

**Persistence:**  
Stored in ModData: `"DynamicTrading_Factions"`  
Server authority, transmitted to clients

## Lifecycle - Initialization

### Lifecycle.Init()

Initializes faction system on game start. Creates Independent failsafe faction and populates towns.

**Process:**

1. **ModData Setup** - Creates `DynamicTrading_Factions` if not exists
2. **Failsafe Faction** - Creates "Independent" nomadic faction if missing:
   ```lua
   {
       id = "Independent",
       name = "Independent Traders",
       memberCount = 10,
       isNomadic = true,
       homeCoords = nil  -- No fixed home
   }
   ```
3. **Town Population Check** - If no town factions exist, triggers RepopulateTowns()
4. **Data Integrity** - Validates existing faction data:
   - Ensures reputation is table
   - Ensures wealth is number (default 1000)
   - Initializes ActiveFlashEvent if missing
   - Initializes consecutiveStableDays if missing
5. **Transmit** - Syncs to clients

**When Called:** OnGameBoot, OnServerStarted

**Independent Faction:**
- Always exists (nomadic failsafe)
- Cannot die out (auto-replenishes)
- Minimum 10 members, $5000 wealth, 500 food
- Traders spawn globally, not tied to locations

---

### Lifecycle.RepopulateTowns()

Creates initial faction population for all configured towns.

**Process:**

1. Iterate DT_FactionLocations (Rosewood, Muldraugh, WestPoint, Riverside, Louisville)
2. For each town:
   - Get `MaxFactionsPerTown` from sandbox (default 2)
   - Create that many factions with unique IDs
3. Faction ID format: `{townName}_{randomNumber}`
   - Example: `Rosewood_243817`, `Muldraugh_782934`

**Configuration:**
- `SandboxVars.DynamicTrading.MaxFactionsPerTown` (default 2)
- `SandboxVars.DynamicTrading.FactionStartPop` (default 3-10 members)

**Usage:**
```lua
-- Creates 2 factions per town
-- Total: 2 × 5 towns = 10 initial factions + Independent = 11 total
Lifecycle.RepopulateTowns()
```

---

### Lifecycle.CreateFaction(factionID, initialData)

Creates new faction with random name, assigned home, and generated roster.

**Parameters:**
- `factionID` (string) - Unique faction identifier
- `initialData` (table) - Optional configuration:
  - `town` (string) - Town name for location assignment
  - `memberCount` (number) - Initial population
  - `isNomadic` (boolean) - If true, no home assigned
  - `stockpile` (table) - Starting resources
  - `wealth` (number) - Starting cash
  - `state` (string) - Initial state

**Process:**

1. **Name Generation**
   - If nomadic: "Independent Traders"
   - Otherwise: Random from DT_FactionNames.Generate()
     - Examples: "The Iron Vanguard", "Muldraugh Survivors", "The Steel Brotherhood"

2. **Home Assignment**
   - Calls `DT_FactionLocationManager.AssignHome(factionID, town)`
   - Returns: `{ x, y, z, name="Rosewood Fire Station", town="Rosewood" }`
   - Each town has 10-15+ unique locations
   - Prevents overlap (each location assigned to one faction)

3. **Default Values**
   ```lua
   {
       stockpile = { food=200, ammo=100, meds=50, fuel=25 },
       memberCount = SandboxVars.DynamicTrading.FactionStartPop or 10,
       wealth = 1000,
       reputation = {},
       starvationDays = 0,
       consecutiveStableDays = 0,
       ActiveFlashEvent = { id=nil, expires=0 },
       state = "Stable"
   }
   ```

4. **Roster Generation** - Calls `GenerateRoster(factionID)` to create souls

5. **Transmit & Log** - Syncs to clients and prints confirmation

**Usage:**
```lua
-- Create custom faction
DynamicTrading_Factions.CreateFaction("CustomFaction_001", {
    town = "Muldraugh",
    memberCount = 15,
    wealth = 5000,
    stockpile = { food=500, ammo=200, meds=100, fuel=50 }
})
```

---

### Lifecycle.GenerateRoster(factionID)

Creates soul entries for all faction members in DynamicTrading_Roster.

**Process:**

1. **Clear Existing** - Removes any previous souls for this faction
2. **Get Archetypes** - Collects all registered archetypes
3. **For each member:**
   - Random archetype assignment
   - Random scatter position from homeCoords (±10 tiles)
   - Call `DynamicTrading_Roster.AddSoul(factionID, archetype, position)`

**Scatter Logic:**
```lua
scatteredHome = {
    x = home.x + Random(-10, +10),
    y = home.y + Random(-10, +10),
    z = home.z or 0
}
```

**Purpose:**
- Distributes traders around faction base
- Prevents all traders in exact same location
- Each soul gets unique UUID in roster system

**Integration:** See @DynamicTrading_Roster.lua for soul management

## Simulation - Daily Update

### Simulation.UpdateDaily()

Runs complete faction economy simulation cycle each in-game day.

**Execution:** Called by `OnDynamicTradingDailySimulation` event

**Sandbox Configuration:**
- `FactionDailyConsumption` (0.1-5.0, default 1.0) - Consumption multiplier
- `FactionDeathThreshold` (1-10, default 3) - Days starving before death
- `FactionGrowthChance` (0-100, default 50) - % chance to recruit if prosperous
- `FactionRespawnChance` (0-100, default 10) - % chance new faction spawns

**Full Simulation Steps:**

#### **Step 0: Event Processing**

Calls `DynamicTrading.Events.UpdateFaction(faction)` to:
- Check event expiration
- Apply event modifiers
- Trigger/end flash events
- Update event cooldowns

#### **Step 1: Production Calculation**

Based on faction roster composition:

```lua
production = { food=0, ammo=0, meds=0, fuel=0 }

For each soul in faction:
    archetype = soul's archetype
    For each allocation in archetype.allocations:
        resourceType = DynamicTrading.Config.ResourceMap[tag]
        production[resourceType] += (score × ProductionMultiplier)

stockpile += production
```

**Resource Mapping:**
- `"Food.*"` tags → food production
- `"Medical.*"` tags → meds production
- `"Ammo.*"` tags → ammo production
- `"Resource.Fuel"` tags → fuel production

**Production Multiplier:**  
Configured in `DynamicTrading.Config.Sim.ProductionMultiplier` (default 2.0)

**Example:**
```
Farmer archetype: allocations include { tags={"Food.Fresh"}, count=6 }
ResourceMap["Food.Fresh"] = "food"
Production: 6 × 2.0 = 12 food per day per farmer
```

#### **Step 2: Event Casualties (Distributed)**

If faction has `ActiveFlashEvent` with `targetCasualties`:

1. **Calculate Daily Casualties:**
   ```lua
   hoursLeft = event.expires - currentHour
   daysLeft = ceil(hoursLeft / 24)
   killToday = ceil(targetCasualties / daysLeft)
   ```

2. **Add RNG Variance:** 30% chance to reduce by 1
3. **Apply Deaths:**
   - `memberCount -= killToday`
   - `event.targetCasualties -= killToday`
   - Call `DynamicTrading_Roster.RemoveSoul(factionID, killToday)`

**Example:**
```
Event: War (30 targetCasualties, 5 days remaining)
Day 1: Kill 6 (30/5)
Day 2: Kill 6 (24/4)
Day 3: Kill 6 (18/3)
Day 4: Kill 6 (12/2)
Day 5: Kill 6 (6/1)
```

#### **Step 3: Attrition (Resource-Dependent Casualties)**

If event defines `attrition`:

```lua
attrition = {
    resource = "meds",  -- Resource type needed
    pct = 0.4,          -- 40% of faction affected
    cost = 1.5          -- 1.5 resource per affected person
}
```

**Process:**

1. **Calculate Affected:** `affectedCount = floor(memberCount × pct)`
2. **Calculate Need:** `totalNeeded = affectedCount × cost`
3. **Check Stockpile:**
   - If `stockpile[resource] >= totalNeeded`:
     - Subtract resources, no deaths
   - Else:
     - **20% of affected die:** `casualties = ceil(affectedCount × 0.2)`
     - `memberCount -= casualties`
     - Remove souls
     - Set state to "Starving"

**Example:**
```
Faction: 50 members
Event: Plague (meds attrition, 40% affected, 1.5 meds/person)
Affected: 20 people
Need: 30 meds

If stockpile.meds >= 30: Pay 30 meds, no deaths
If stockpile.meds < 30: 4 people die (20 × 0.2)
```

#### **Step 4: Daily Consumption**

Standard resource burn based on population:

```lua
BaseConsumption = { food=1, meds=0.1 }  -- Per person per day

foodBurn = memberCount × 1.0 × consumptionMult × eventModifier
medsBurn = memberCount × 0.1 × consumptionMult × eventModifier

stockpile.food -= foodBurn
stockpile.meds -= medsBurn
```

**Event Modifiers:**  
Events can increase consumption (e.g., winter = +50% food burn)

**Example:**
```
Faction: 20 members
Food burn: 20 × 1.0 × 1.0 = 20 food/day
Meds burn: 20 × 0.1 × 1.0 = 2 meds/day
```

#### **Step 5: Starvation & Death**

If `stockpile.food < 0`:

1. **Clamp food to 0**
2. **Increment starvationDays**
3. **If starvationDays >= deathThreshold:**
   ```lua
   deaths = ceil(memberCount × DeathRate)  -- DeathRate typically 0.1-0.2
   deaths = max(1, deaths)  -- At least 1 dies
   memberCount -= deaths
   RemoveSoul(factionID, deaths)
   ```

**Death Threshold:**  
Sandbox configurable (default 3)  
3 consecutive days of starvation → start dying

**Death Rate:**  
Configured in `DynamicTrading.Config.Sim.DeathRate` (default 0.1 = 10% die)

**Example:**
```
Day 1: No food, starvationDays = 1
Day 2: No food, starvationDays = 2
Day 3: No food, starvationDays = 3
Day 4: Threshold reached! 10% of faction dies
Day 5: Still no food, another 10% dies
```

**Faction Death:**  
If `memberCount <= 0`, faction removed from database and roster cleared

#### **Step 6: Growth & Recruitment**

If faction is prosperous, may recruit new member:

**Conditions:**
1. **Surplus Food:** `stockpile.food > (memberCount × baseConsumption × 7)`
   - Must have 7+ days of food buffer
2. **Growth Roll:** `Random(0-100) < growthChance` (default 50%)
3. **Engine Check:** `DynamicTrading_Engine.ConsumeRecruit()` (global recruitment cap)

**If All Conditions Met:**
```lua
memberCount += 1
stockpile.food -= RecruitCost.food  -- Default 50 food

-- Add soul to roster
randomArchetype = Random archetype from registry
DynamicTrading_Roster.AddSoul(factionID, randomArchetype, scatteredHome)
```

**Recruit Cost:**  
Configured in `DynamicTrading.Config.Sim.RecruitCost` (default { food=50 })

**Example:**
```
Faction: 10 members, 300 food
Required buffer: 10 × 1 × 7 = 70 food
Surplus: 300 > 70 ✓
Growth roll: 45 < 50 ✓
Engine allows ✓

Result: +1 member, -50 food → 11 members, 250 food
```

#### **Step 7: State Update**

Faction state reflects resource situation:

```lua
if starvationDays > 0:
    state = "Starving"
elseif stockpile.food < (memberCount × 5):
    state = "Vulnerable"  -- Less than 5 days food
else:
    state = "Stable"
```

**State Transitions:**
- **Stable** → **Vulnerable:** Food drops below 5-day buffer
- **Vulnerable** → **Starving:** Food reaches 0
- **Starving** → **Dead:** memberCount reaches 0
- **Starving** → **Stable:** Food restocked (trade or production)

#### **Step 8: Passive Attrition (Global)**

If global demographics modifier active:

```lua
attritionAdd = DynamicTrading.Events.GetDemographicsModifier("attritionAdd")
passiveDeaths = floor(memberCount × attritionAdd)
memberCount -= passiveDeaths
```

**Purpose:** Long-term population pressure from world conditions

#### **Step 9: Wealth Generation**

Factions earn daily income from internal trading/scavenging:

```lua
dailyEarn = memberCount × 50  -- $50 per member per day
wealth += dailyEarn
```

**Example:**
```
20 members × $50 = $1000/day passive income
```

**Independent Faction Bonus:**
```lua
memberCount = max(memberCount, 10)  -- Never drops below 10
stockpile.food = max(stockpile.food, 500)
wealth = max(wealth, 5000)
state = "Stable"  -- Always stable
```

#### **Step 10: Dynamic Respawn**

If town has fewer factions than max, chance to spawn new faction:

```lua
For each town:
    currentFactionCount = Count factions in this town
    if currentFactionCount < MaxFactionsPerTown:
        if Random(0-100) < FactionRespawnChance:
            CreateFaction(townName + "_" + Random_ID, {
                town = townName,
                memberCount = FactionStartPop
            })
```

**Respawn Chance:**  
Sandbox configurable (default 10%)  
Checked daily per town  
Ensures long-term faction presence even after wipeouts

**Example:**
```
Muldraugh has 1 faction (max 2)
10% respawn chance rolls 7 → Success!
New faction "Muldraugh_582947" created with 10 members
```

## Configuration Parameters

### Sandbox Variables

```lua
SandboxVars.DynamicTrading = {
    MaxFactionsPerTown = 2,           -- Factions per town (1-5)
    FactionStartPop = 10,             -- Initial members (3-50)
    FactionDailyConsumption = 1.0,    -- Consumption mult (0.1-5.0)
    FactionDeathThreshold = 3,        -- Days before death (1-10)
    FactionGrowthChance = 50,         -- Recruit chance % (0-100)
    FactionRespawnChance = 10         -- New faction chance % (0-100)
}
```

### Economy Config

```lua
DynamicTrading.Config.Sim = {
    ProductionMultiplier = 2.0,       -- Production scale
    DeathRate = 0.1,                  -- % die per starvation tick
    BaseConsumption = {
        food = 1.0,                   -- Food per person per day
        meds = 0.1                    -- Meds per person per day
    },
    RecruitCost = {
        food = 50                     -- Food cost to recruit
    }
}
```

### Resource Mapping

```lua
DynamicTrading.Config.ResourceMap = {
    ["Food"] = "food",
    ["Food.Fresh"] = "food",
    ["Food.Canned"] = "food",
    ["Medical"] = "meds",
    ["Medical.Supply"] = "meds",
    ["Ammo"] = "ammo",
    ["Weapon.Ammo"] = "ammo",
    ["Resource.Fuel"] = "fuel"
}
```

## Performance Considerations

- **Single daily update** - Not per-hour, reduces CPU load
- **Batch soul removal** - RemoveSoul(N) removes N at once
- **Lazy wealth calculation** - Simple multiplication, no complex trade tracking
- **Faction death cleanup** - Removes from both ModData and Roster
- **Respawn throttled** - Only checks if below max, 10% chance

## Best Practices

1. **Balance consumption vs production** - Ensure archetypes produce enough
2. **Set realistic death thresholds** - 3-5 days typical
3. **Monitor faction counts** - Use debug to track deaths vs respawns
4. **Test event impacts** - Casualties can wipe factions quickly
5. **Adjust respawn chance** - Higher for unstable worlds, lower for stable
6. **Configure max factions** - More = busier economy, more performance cost
7. **Use Independent as template** - Copy its resilience patterns for custom factions

## Common Patterns

### Creating Custom Faction
```lua
Events.OnGameBoot.Add(function()
    DynamicTrading_Factions.CreateFaction("PlayerAlliance", {
        town = "Rosewood",
        memberCount = 20,
        wealth = 10000,
        stockpile = { food=1000, ammo=500, meds=200, fuel=100 },
        reputation = { ["PlayerName"] = 100 }  -- Max trust
    })
end)
```

### Monitoring Faction Health
```lua
local faction = ModData.get("DynamicTrading_Factions")["Rosewood_123456"]
print("State: " .. faction.state)
print("Members: " .. faction.memberCount)
print("Food: " .. faction.stockpile.food .. " days")
print("Starvation: " .. faction.starvationDays .. " days")
```

### Triggering Manual Event
```lua
local faction = ModData.get("DynamicTrading_Factions")["Rosewood_123456"]
faction.ActiveFlashEvent = {
    id = "War",
    expires = getGameTime():getWorldAgeHours() + (24 * 7),  -- 7 days
    targetCasualties = 10
}
```
