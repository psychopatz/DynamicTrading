Title: How to Create & Register New Items
Tags: [guide, items, creation, tutorial, registration]

QUICK START (5-minute guide):

Step 1: Identify the Category
- Food.Cooking? → Edit DT_Cooking.lua
- Weapon? → Edit DT_Weapon.lua
- New category? → Create DT_NewCategory.lua

Step 2: Get Base.ItemID
- Open Zomboid PZ Lua documentation
- Find item in Classes.lua or item list
- Copy exact ID (e.g., "Base.Bread", "Base.ModItem.radioearphone")

Step 3: Define Base Price
- Common items (food, resources): 4-30
- Uncommon items (tools, clothing): 30-100
- Rare items (weapons, equipment): 100-300
- Epic items (vehicles, special): 300+

Step 4: Assign Tags
- Primary: "Category.Subcategory" (required)
- Secondary: "Rarity.Common|Uncommon|Rare|Epic|Legendary" (required)
- Optional: "Winter", "Illegal", "Seasonal", "Quest", "Restricted"

Step 5: Set Stock Range
- Common items: {min=2, max=6}
- Uncommon: {min=1, max=4}
- Rare: {min=0, max=2}
- Epic/Legendary: {min=0, max=1}

Step 6: Add to Category File
```lua
-- File: DT_Cooking.lua (example)
local items = {
  -- existing items...
  {item="Base.Bread", basePrice=8, tags={"Food.Cooking", "Rarity.Common"}, stockRange={min=3, max=8}},
  -- YOUR NEW ITEM:
  {item="Base.CakeMix", basePrice=12, tags={"Food.Cooking", "Rarity.Uncommon"}, stockRange={min=1, max=3}},
}
DynamicTrading.RegisterBatch(items)
```

Step 7: Verify & Test
- Load game
- Check /dtm debug
- Search item name in NPC inventories
- Confirm price & quantity displayed correctly

DETAILED DECISION TREE:

Question 1: Is this a food item?
  YES → Use Food/ subfolder
    → Cooking (baked goods, condiments, spices)?
    → Drink (beverages, juices, wine)?
    → Meat (butcher cuts)?
    → Perishable (produce, dairy, eggs)?
    → NonPerishable (canned, preserved, dry)?
  NO → Continue to Question 2

Question 2: Is this a drainable item (fuel, oil, liquid)?
  YES → Use DT_Fluids.lua
    → Define fluidType: "fuel" | "oil" | "chemical" | "beverage" | "medicine"
    → Set fluidCapacity: typically 1.0
    → Set fluidInitial: fill percentage (0.2-0.95)
    → [See FluidSystem chunk for details]
  NO → Continue to Question 3

Question 3: What category best fits?
  Clothing → DT_Clothing.lua
  Tools → DT_Tool.lua
  Weapons → DT_Weapon.lua
  Electronics → DT_Electronics.lua
  Medical → DT_Medical.lua
  Containers → DT_Container.lua
  Building/Appliance → DT_Appliance.lua
  Resources/Materials → DT_Resource.lua
  Books/Maps → DT_Literature.lua
  Vehicle parts → DT_Vehicle.lua
  Misc → DT_Misc.lua

RARITY TIER GUIDELINES:

Common (Rarity.Common) - Abundant, found everywhere
  Price: 4-20
  Stock range: {min=2, max=6}
  NPC allocation: 80% of NPCs likely to have
  Examples: Food items, basic tools, ammo
  Multiplier: 0.9x in economy events

Uncommon (Rarity.Uncommon) - Moderately available
  Price: 20-50
  Stock range: {min=1, max=4}
  NPC allocation: 60% of NPCs likely to have
  Examples: Quality tools, ammunition types, electronics
  Multiplier: 1.0x in economy events

Rare (Rarity.Rare) - Limited availability
  Price: 50-150
  Stock range: {min=0, max=2}
  NPC allocation: 30% of NPCs have
  Examples: Specialized weapons, valuable materials
  Multiplier: 1.1x in economy events

Epic (Rarity.Epic) - Very rare, specialized
  Price: 150-400
  Stock range: {min=0, max=1}
  NPC allocation: 10% of NPCs have
  Examples: Scopes, high-tier weapons, unique items
  Multiplier: 1.2x in economy events

Legendary (Rarity.Legendary) - Extremely rare, unique
  Price: 400+
  Stock range: {min=0, max=1}
  NPC allocation: <5% of NPCs have
  Examples: Unique quest items, special equipment
  Multiplier: 1.3x in economy events

TAG ASSIGNMENT RULES:

Primary Tag Format: "Category.Subcategory"
  - Food.Cooking, Food.Drink, Food.Meat, Food.Perishable, Food.NonPerishable
  - Weapon.Melee, Weapon.Ranged
  - Clothing.Head, Clothing.Body, Clothing.Legs, Clothing.Hands, Clothing.Feet
  - Tool.Crafting, Tool.Construction, Tool.Maintenance
  - Electronics.Radio, Electronics.Lighting, Electronics.Power
  - Medical.Surgical, Medical.Consumable, Medical.Supply

Secondary Tag: Always "Rarity.X"
  - Rarity.Common
  - Rarity.Uncommon
  - Rarity.Rare
  - Rarity.Epic
  - Rarity.Legendary

Optional Tags (zero or more):
  - Winter: Item more available in winter season
  - Summer: Item more available in summer
  - Illegal: Illegal/contraband items (reduced by law enforcement)
  - Seasonal: Time-limited availability
  - Quest: Quest item marker
  - Restricted: Government-restricted items
  - Luxury: High-value status symbol
  - Cursed: Special/superstitious items (flavor)

Multi-tag Example:
```lua
{
  item="Base.Whiskey",
  basePrice=25,
  tags={"Food.Drink", "Rarity.Uncommon", "Illegal", "Winter"},
  stockRange={min=1, max=3}
}
```
Effect: Drink, uncommon rarity, illegal (affects pricing), more common in winter

STOCK RANGE SEMANTICS:

{min=X, max=Y} = when allocated to NPC, spawn X-Y quantity randomly

Examples:
  - {min=1, max=1} = exactly 1 (unique items, quest items)
  - {min=0, max=1} = either 0 or 1 (very rare, 50% chance to get any)
  - {min=2, max=6} = common staple (most NPCs have 2-6)
  - {min=3, max=8} = abundant, frequently restocked

NPC Restock Logic:
- Each "trading day" (every 12 hours in-game)
- Check each archetype's item allocation
- For each item: roll between min-max
- Add new quantity to NPC inventory
- Price adjusted by economy events

Allocation to Archetype Example:
```lua
-- Archetype: Chef
{
  archetypeID = "chef",
  name = "Chef/Cook",
  tags = {"Food.Cooking", "Food.NonPerishable"},
  items = {
    -- These items allocated to ALL chefs
    {itemID="Base.Sugar", basePrice=8, weight=1.0},
    {itemID="Base.Salt", basePrice=6, weight=0.9},
    {itemID="Base.Bak_CakeMix", basePrice=12, weight=0.7},  -- NEW ITEM
  }
}
```

When chef is created:
- For each item in allocation
- Roll random quantity: 0-6 for Sugar (high common)
- Roll random quantity: 0-3 for CakeMix (uncommon)
- Store in chef's inventory
- [See ArchetypeDefinitions/AllocationPatterns for details]

PRICE CALCULATION:

Base prices are adjusted by:
1. Economy Events (priceMult = 1.4 for shortage, 0.6 for glut)
2. Faction Reputation (reputation modifier ±10%)
3. NPC Personal Wealth (wealthy NPCs charge more)
4. Rarity Tier (handled in tag weights)
5. Partial Fills (for fluids/drainables)

Player sees: Final Price = BasePrice * EventMult * ReputationMult * WealthMult

Example transaction:
- Base price: 50
- Event active: shortage (1.4x)
- Player reputation: +50 (-10% discount = 0.9x)
- NPC wealth: wealthy (+15% = 1.15x)
- Final: 50 * 1.4 * 0.9 * 1.15 = 72.45

CUSTOM ITEM VALIDATION:

Before adding new item, verify:
1. Base.ItemID exists in Zomboid base game
2. Price is > 0 number type
3. Primary tag exists in Tags registry
4. Secondary tag is "Rarity.*" with valid tier
5. stockRange: min <= max, both positive integers
6. Tags don't conflict (e.g., Food.Clothing invalid)

Validation check (in-game):
```
/dtm validate items
```
Returns:
- ✓ All items valid
- ✗ ItemID not found: Base.InvalidItem
- ✗ Invalid price: -50 (must be > 0)
- ✗ Tag not registered: InvalidTag

MODDING EXTENSIONS (Advanced):

Add item from another mod:
```lua
{item="MyMod.CustomBread", basePrice=15, tags={"Food.Cooking", "Rarity.Rare"}, stockRange={min=0, max=2}}
```

Requirements:
- Mod must be loaded before DynamicTrading
- Item must have valid item definition in mod
- Prefix with ModName: "ModName.ItemID"

Define new category tag:
```lua
DynamicTrading.Config.AddTag("Food.NewSubcategory", {parent="Food", weight=1.0})
```
Then use in items:
```lua
{item="Base.SomeFood", basePrice=10, tags={"Food.NewSubcategory", "Rarity.Common"}, stockRange={min=2, max=6}}
```
