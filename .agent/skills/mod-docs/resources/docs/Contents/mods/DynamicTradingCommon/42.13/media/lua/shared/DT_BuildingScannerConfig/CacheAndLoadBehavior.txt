Title: Cache and Lookup Load Behavior
Tags: [chunk, internal]

LOCATION: Contents/mods/DynamicTradingCommon/42.13/media/lua/shared/DT_BuildingScannerConfig.lua
PURPOSE: Explain how scanner results are loaded from ModData and prepared for fast lookup.

LOAD PROCESS:
1. `DTM.LoadBuildings()` returns early if both cache tables already exist.
2. It reads `ModData.getOrCreate("DT_Buildings")` and prefers `locations` if present.
3. If no persisted data is found, it falls back to local scanning.
4. It builds `DTM.BuildingLookup["x,y"] = buildingRecord` for O(1) coordinate resolution.

DETAIL EXTRACTION:
- `DTM.GetBuildingDetails(def)` captures room counts, unique rooms, alarm/visited flags, and a preferred primary room.
- Preferred room logic promotes configured room names over raw frequency when available.

DEBUG SUPPORT:
- `DTM.Log(message)` prints only when `DTM.Config.Debug` is enabled.
- Debug output is useful for zone taxonomy tuning and scanner validation.
