Title: Wallet Loot Generation Logic (Server Chunk)
Tags: [chunk, internal]

WALLET DROP SYSTEM:
Triggered when zombie dies. Server calculates currency loot for inventory.

PROBABILITY FLOW:

function CalculateWalletContents(player)
  
  -- Step 1: Check if wallet is empty
  if random(0, 100) <= WalletEmptyChance (default 35%) then
    return {} -- No money drop
  end
  
  -- Step 2: Check for jackpot
  if random(0, 100) <= WalletJackpotChance (default 5%) then
    -- Zombies very rarely drop lucky amounts
    amount = random(WalletMaxCash * 0.8, WalletMaxCash * 1.5)
    return CreateMoneyBundles(amount)  -- 80-150% of max
  end
  
  -- Step 3: Tiered distribution (normal case)
  roll = random(0, 100)
  if roll < 60 then
    -- 60% low tier
    amount = random(WalletMinCash, WalletMaxCash * 0.3)
  elseif roll < 90 then
    -- 30% mid tier
    amount = random(WalletMaxCash * 0.3, WalletMaxCash * 0.6)
  else
    -- 10% high tier
    amount = random(WalletMaxCash * 0.6, WalletMaxCash)
  end
  
  return CreateMoneyBundles(amount)
end

SANDBOX OPTIONS (Default Values):
- WalletMinCash = 1 (minimum loose coin)
- WalletMaxCash = 100 (maximum single wallet)
- WalletEmptyChance = 35 (% chance zombie has no wallet)
- WalletJackpotChance = 5 (% chance of bonus drop)

MONEY BUNDLE CREATION:
function CreateMoneyBundles(totalAmount)
  result = {}
  
  -- Create MoneyBundle items (100 each)
  bundles = std.floor(totalAmount / 100)
  for i = 1, bundles do
    table.insert(result, {item="Base.MoneyBundle", quantity=1})
  end
  
  -- Create loose Money for remainder
  remainder = totalAmount % 100
  if remainder > 0 then
    table.insert(result, {item="Base.Money", quantity=remainder})
  end
  
  return result
end

INVENTORY IMPACT:
MoneyBundle items take 1 slot (100 units)
Loose Money stacks (up to defined stack size)

Efficient packing:
- 345 total: 3x MoneyBundle (300) + 45 loose = 4 inventory slots
- Better than: 345 loose Money items = 4+ slots (depends on stack size)

NETWORK SYNC:
SP: CreateMoneyBundles result added directly to inventory
MP: SendResponse() → server calculates → AddItem() called → network-synced to all clients

MODDATA PERSISTENCE:
Wallet amounts NOT persisted (calculated on each zombie death)
Different zombies = different chances each time
Allows farm-able but not exploitable currency generation
