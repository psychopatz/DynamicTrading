Title: Faction System (V1/V2)
Tags: [factions, reputation, politics]

The Faction system governs trader relationships and global resource availability.

## Core Features
1. **Reputation Level:** Affects prices, available items, and whether certain traders will even speak to you.
2. **Faction Territory:** Influences where certain NPCs (V2) can spawn and which frequencies (V1) are active.
3. **Regional Logic:** Factions compete for resources, affecting the global economy.

## Integration
Factions are handled via the `DT_FactionManager.lua` script, ensuring that reputation gains in physical combat (V2) or trade (V1/V2) are persistent and globally synced.
