Title: Tag Hierarchy & Matching (Tags Chunk)
Tags: [chunk, internal]

TAG REGISTRATION EXAMPLE:
DynamicTrading.Tags = {
  Rarity = {
    Common = {priceMult=1.0, weight=40},
    Uncommon = {priceMult=1.2, weight=30},
    Rare = {priceMult=1.8, weight=20},
    Legendary = {priceMult=3.5, weight=10}
  },
  Categories = {
    ["Food.Perishable"] = {priceMult=1.0, weight=1.0},
    ["Food.Perishable.Fish"] = {priceMult=1.0, weight=1.0},
    ["Food.NonPerishable"] = {priceMult=0.9, weight=1.0},
    ["Tool.General"] = {priceMult=1.5, weight=0.8},
    ["Weapon.Ranged.Firearm"] = {priceMult=2.0, weight=0.5},
    ...
  },
  Conditional = {
    Winter = {weight=0, priceMult=1.0},     -- Disabled default
    Harvest = {weight=0, priceMult=0.8},   -- Disabled default
    Illegal = {weight=0.2, priceMult=2.5}, -- Restricted
    Quest = {weight=0, priceMult=1.0}      -- Quest-only
  }
}

MATCHING ALGORITHM:
function MatchesAllTags(itemTags, requiredTags)
  for _, requiredTag in ipairs(requiredTags) do
    local found = false
    for _, itemTag in ipairs(itemTags) do
      if itemTag == requiredTag or
         itemTag:sub(1, #requiredTag) == requiredTag and
         itemTag:sub(#requiredTag + 1, #requiredTag + 1) == "." then
        found = true
        break
      end
    end
    if not found then return false end
  end
  return true
end

EXAMPLES:
✓ MatchesAllTags(["Food.Perishable.Fish"], ["Food.Perishable"])
  → itemTag "Food.Perishable.Fish" has parent "Food.Perishable"

✓ MatchesAllTags(["Food.Perishable.Fish", "Rarity.Common"], ["Food", "Rarity"])
  → Both parents present in item tags

✗ MatchesAllTags(["Tool.General"], ["Weapon"])
  → "Tool" not parent of "Weapon"

WEIGHT-BASED SELECTION:
When allocating stock, PickFromWeightedPool respects weights:
- Common foods: weight=40 → selected 40% more often
- Rare weapons: weight=20 → selected 20% more often
- Winter items: weight=0 (default) → never selected (unless Winter event active)

PRICE CALCULATION:
finalPrice = basePrice * rarityMult * categoryMult * eventMult * sandboxMult
Example: Fish (basePrice=25)
- Rarity.Common: 25 * 1.0 = 25
- Rarity.Uncommon: 25 * 1.2 = 30
- Rarity.Rare: 25 * 1.8 = 45
- Rarity.Legendary: 25 * 3.5 = 87.5
