Title: Economy System (V1/V2)
Tags: [economy, logic, pricing]

The Dynamic Trading economy is a shared system across all interaction modules.

## Core Features
1. **Dynamic Pricing:** Prices fluctuate based on supply, demand, and faction state.
2. **Stock Management:** Traders have finite stock that replenishes over time or via player trades.
3. **Weight-Based Pricing:** Heavy items generally cost more to simulate logistics overhead.

## Unified Logic
Both Radio (V1) and NPC (V2) interfaces read from the same `DynamicTrading_Stock` ModData. Changes made via one interface are immediately reflected in the other.
