PATTERN 1: FISHING SPECIALIST (Angler)

RegisterArchetype("Angler", {
  name = "River Trader",
  allocations = {
    { tags={"Food.Perishable.Fish"}, count=6, min=1, max=3 },
    { tags={"Tool.Resource.Angler"}, count=4, min=1, max=2 },
    { tags={"Food.Cooking"}, count=2, min=1, max=1 }
  },
  expertTags = {"Food.Perishable.Fish", "Tool.Resource.Angler"},
  wants = {"Tool.General"=1.2},
  forbid = {"Weapon.Ranged.Firearm", "Electronics"}
})

Personality: River dwelling, fishing-focused. Has cooking ingredients (prepares catches). Wants general repair tools.
Restrictions: No firearms (isolation), no electronics (remote location).

PATTERN 2: CULINARY EXPERT (Chef)

RegisterArchetype("Chef", {
  name = "Master Cook",
  allocations = {
    { tags={"Food.Cooking"}, count=8, min=2, max=4 },
    { tags={"Food.Perishable"}, count=6, min=1, max=3 },
    { tags={"Food.NonPerishable"}, count=4, min=1, max=2 },
    { tags={"Appliance"}, count=2, min=1, max=1 },
    { tags={"Tool.General"}, count=2, min=1, max=1 }
  },
  expertTags = {"Food.Cooking", "Food.Perishable", "Appliance"},
  wants = {"Food"=1.3},
  forbid = {"Weapon", "Illegal"}
})

Personality: Culinary focus, kitchen-obsessed. Buys cooking components aggressively. Pacifist.
High count numbers (8, 6, 4) show main allocations. Few restrictions (no weapons, illegal).

PATTERN 3: MECHANIC (Engineer)

RegisterArchetype("Mechanic", {
  name = "Town Mechanic",
  allocations = {
    { tags={"Tool.Resource.Mechanic"}, count=10, min=2, max=4 },
    { tags={"Vehicle"}, count=6, min=1, max=2 },
    { tags={"Resource"}, count=5, min=1, max=3 },
    { tags={"Tool.General"}, count=4, min=1, max=2 },
    { tags={"Electronics"}, count=3, min=1, max=1 }
  },
  expertTags = {"Tool.Resource.Mechanic", "Vehicle"},
  wants = {"Resource"=1.25, "Tool"=1.1},
  forbid = {"Food.Perishable", "Illegal"}
})

Personality: Tool/vehicle expert. Wants materials & tools (eager buyer). Refuses perishable food.

ALLOCATION ALGORITHM EXECUTION:
For allocation {tags={"Food.Perishable.Fish"}, count=6, min=1, max=3}:
1. Find matching items (MasterList items with "Food.Perishable.Fish" tag)
   - Base.Catfish, Base.Salmon, Base.Trout, Base.Bass, ...
2. Apply rarity weights (Common: 40%, Uncommon: 30%, Rare: 20%, Legendary: 10%)
3. PickFromWeightedPool() 6 times → selects 6 items respecting weights
4. For each selected item: quantity = random(1, 3)
5. Result: Angler.stock = {
     {item="Base.Catfish", qty=2},
     {item="Base.Salmon", qty=1},
     {item="Base.Trout", qty=3},
     {item="Base.Bass", qty=2},
     {item="Base.Pike", qty=1},
     {item="Base.Carp", qty=2}
   }

DESIGN PRINCIPLES:
- Allocations should reflect IRL profession (Chef = food, Mechanic = tools)
- expertTags affect only sell-to-NPC (player gets bonus)
- wants affect only buy-from-NPC (NPC pays more)
- forbid prevents trades completely (personality enforcement)
- Higher count = more important allocations
- Lower min/max = rare luxury items, higher = common staples
