Title: Dialogue Generation Workflow (Dialogue Chunk)
Tags: [chunk, internal]

COMPLETE DIALOGUE FLOW WALKTHROUGH:

SCENARIO: Player approaches Angler NPC in morning, raining weather

1. UI calls DT_DialogueManager.GenerateGreeting(trader_angler)

2. Inner execution:
   a. DialogueManager.GenerateGreeting(trader)
      → Calls GetDialoguePool(archetype, "Greetings", subContext)
   
   b. GetDialoguePool determines subContext:
      - Check time of day: 6am-12pm → "Morning"
      - Check weather: isRaining() → "Raining"
      - Return: Dialogue.Archetypes["Angler"]["Greetings"]["EN"]["Raining"] pool
      
   c. If "Raining" context missing, fallback to "Default" context

3. Pool retrieval example:
   Dialogue.Archetypes["Angler"]["Greetings"]["EN"]["Raining"] = {
     {weight=1, text="Nasty weather today, {player}."},
     {weight=1, text="Fish don't bite much in rain..."},
     {weight=2, text="Come inside, {player}, it's pouring!"},
     {weight=1, text="The river's churning. {npc.name} here."}
   }

4. PickRandom(pool) selects weighted random:
   Total weight = 1+1+2+1 = 5
   Random chance:
   - 20% (1/5) → "Nasty weather today, {player}."
   - 20% (1/5) → "Fish don't bite much in rain..."
   - 40% (2/5) → "Come inside, {player}, it's pouring!"
   - 20% (1/5) → "The river's churning. {npc.name} here."
   
   Assume selected: "Come inside, {player}, it's pouring!"

5. FormatMessage substitution:
   Input text: "Come inside, {player}, it's pouring!"
   Args: {
     player={firstName="John", surname="Smith"},
     npc={name="River Trader"}
   }
   Substitutions:
   - {player} → "John Smith"
   - {npc.name} → "River Trader"
   
   Result: "Come inside, John Smith, it's pouring!"

6. UI displays dialogue to player:
   [Angler portrait] "Come inside, John Smith, it's pouring!"
   [OK button]

    },
    Night = {
      {weight=1, text="It's getting dark, {player}."}

    Raining = {
      {weight=2, text="Come inside, {player}, it's pouring!"},
      {weight=1, text="Nasty weather today, {player}."}
    }
  }
})

VARIABLE SUBSTITUTION ENGINE:
function FormatMessage(text, args)
  local result = text
  -- Player substitutions
  result = result:gsub("{player}", args.player.firstName .. " " .. args.player.surname)
  result = result:gsub("{player.firstname}", args.player.firstName)
  result = result:gsub("{player.surname}", args.player.surname)
  -- NPC substitutions
  result = result:gsub("{npc}", args.npc.name)
  result = result:gsub("{npc.name}", args.npc.name)
  -- Item/Price substitutions
  result = result:gsub("{item}", args.item or "item")
  result = result:gsub("{price}", formatPrice(args.price or 0))
  return result
end
