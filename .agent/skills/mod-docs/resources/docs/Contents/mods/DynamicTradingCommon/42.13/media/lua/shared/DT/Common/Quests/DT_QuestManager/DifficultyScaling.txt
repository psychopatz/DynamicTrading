Title: Quest Difficulty Scaling & Item Spawn Logic
Tags: [chunk, internal, quests, difficulty, scaling, spawning]

DIFFICULTY LEVELS & SCALING:

Five difficulty tiers:
- Easy: 1 item, basePrice * 0.5 value, common tags
- Normal: 2-3 items, basePrice * 1.0 value, mixed tags
- Hard: 3-5 items, basePrice * 1.5 value, rare tags
- Expert: 4-6 items, basePrice * 2.0 value, epic + rare tags
- Legendary: 5-8 items, basePrice * 3.0 value, epic + legendary tags

Difficulty selection:
- Based on player level (skills, traits, recent encounter difficulty)
- Influenced by: player kills, crafting level, medical skill
- Sandbox option: MinQuestDifficulty, MaxQuestDifficulty

ITEM ALLOCATION TABLE:

Easy quest example:
```
{
  difficulty = "easy",
  primaryItem = "Base.Sugar",    -- common food
  quantity = 1,
  rarity = "common",
  baseValue = 25,
  location = "Kitchen|Store",    -- common places
  timeLimit = 60,                -- 1 game hour
  reward = 50 + (npcLevel * 5)   -- scaling reward
}
```

Hard quest example:
```
{
  difficulty = "hard",
  primaryItem = "Base.RifleScopes", -- rare item
  quantity = 2,
  secondaryItems = {"Base.Bullets", "Base.Backpack"},
  rarity = {"rare", "uncommon", "uncommon"},
  baseValue = 150,
  location = "Warehouse|Factory|Military",  -- dangerous
  timeLimit = 120,
  reward = 250 + (npcLevel * 20)
  hazard = "zombie_density_high"
}
```

VALUE CALCULATION:

Formula: BasePrice + (Rarity Multiplier × Difficulty Multiplier)

Rarity multipliers:
- Common: 0.5x
- Uncommon: 1.0x
- Rare: 1.5x
- Epic: 2.5x
- Legendary: 4.0x

Difficulty multipliers:
- Easy: 1.0x
- Normal: 1.2x
- Hard: 1.5x
- Expert: 2.0x
- Legendary: 3.0x

Example quest value:
- Item: Base.RifleScopes (basePrice=100)
- Rarity: Rare (1.5x)
- Difficulty: Hard (1.5x)
- Item value: 100 * 1.5 * 1.5 = 225
- Total quest reward: 225 + npcLevel bonus

LOCATION SELECTION:

BuildingScanner provides location candidates:
```
GetQuestLocation(difficulty, questType)
  -- Easy: residential, stores (safe)
  -- Normal: mixed buildings
  -- Hard: industrial, farms, remote (dangerous)
  -- Expert: military, prison, hazmat (high zombie density)
```

Location hazard level:
- Residential: low zombie spawn (0-2)
- Commercial: medium (2-4)
- Industrial: high (4-6)
- Military/Prison: extreme (6-8)

Scaling with difficulty:
- Easy: Hazard level 0-1
- Normal: Hazard level 1-3
- Hard: Hazard level 3-5
- Expert: Hazard level 5-7
- Legendary: Hazard level 7-8

QUEST STATE TRACKING:

Active quest stored in ModData:DT_ActiveQuests[playerID]:
```
{
  questID = "quest_001",
  questType = "FetchItem",
  npcID = "npc_baker_001",
  primaryItem = "Base.Sugar",
  itemID = "item_instance_12345",  -- unique instance reference
  location = {x=500, y=600},
  difficulty = "normal",
  createdTime = 234567,  -- in-game hours
  deadline = 234627,     -- +60 hours
  reward = 125,
  status = "active"  -- active|completed|failed|expired
}
```

Item tracking:
- Quest item stored as ModData on actual item instance
- Contains: questID, difficulty, NPCassignment
- Persistence: preserved if item moved/picked up

COMPLETION CONDITIONS:

Quest completes when:
1. Player picks up correct item (questID match)
2. Player delivers to originating NPC
3. NPC validates item identity
4. Reward transferred to player

Failed quest:
- Item destroyed before delivery → quest fails
- Deadline passed → quest expires
- NPC dies → quest fails (no reward)
- Player dies → quest pauses, resumes on respawn

PERSISTENCE & SYNC:

Single-player:
- ModData saved to character .sav file
- Quest items spawned in permanent locations
- Reload game → quest items still there

Multiplayer:
- Server maintains canonical quest state
- Client sends: "Quest/Deliver" command
- Server validates item + NPC alive
- Server transfers reward from NPC wallet
- Server broadcasts update to all clients

REWARD SCALING:

Base reward = item value × difficulty multiplier

Bonus multipliers:
- Speed bonus: Completed < 50% deadline = +25%
- Difficulty bonus: Higher difficulty = +level scaling
- Faction reputation: Positive reputation = +5-10%

Example:
- Item value: 100
- Difficulty multiplier: 1.5 (hard)
- Base reward: 150
- Speed bonus (60 hours taken, 120 available): 150 * 1.25 = 187.5
- Faction bonus (reputation +50): 187.5 * 1.05 = 196.8
- Final reward: ~197 (rounded)
