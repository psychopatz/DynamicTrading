Title: V2: Physical NPC Interaction Module
Tags: [v2, npc, physical]

The V2 module provides the physical world interface for the Dynamic Trading system using the "Soul/Puppet" architecture.

## Feature Parity
V2 shares the exact same core logic as V1:
- **Economy & Factions:** The macro-economy and faction reputation systems are shared.
  - See @economy
  - See @factions
- **Quests & Events:** Quests can be initiated physically and monitored via the radio (V1) or vice versa.

## The Soul & The Puppet
- **The Soul (Roster):** Persistent identity, stats, and memory stored in ModData. This data is what the Radio (V1) also reads from.
- **The Puppet:** Temporary `IsoZombie` or `IsoPlayer` object spawned for physical interaction.
- **Behavior:** NPCs use custom brains to handle physical actions like Guarding, Trading, or Fleeing.

## Logic Flow
- **Interaction:** Triggered when a player enters an active Trader Zone.
- **Spawn:** Server validates and sends `DTNPC_Spawn` command to manifest the Puppet from the Soul.
- **Sync:** Handled via `DTNPC_ClientSync` for multiplayer consistency.

## Synergy with V1
V1 and V2 are two sides of the same coin. An NPC being tracked by V2's system is the same "Soul" available on V1's radio frequencies, though they cannot be in two places at once (Radio vs Physical world).
