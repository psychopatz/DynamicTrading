Dynamic Trading: Smart Documentation System

This system provides token-efficient documentation retrieval for the Dynamic Trading project.

1. Retrieval Methods:
   - Slugs: Logical aliases defined in registry.json (e.g., 'economy', 'factions').
   - Shortcodes: Unique 4-character IDs (e.g., 'wk4b') for maximum token savings.
   - Paths: Raw workspace paths (e.g., 'Contents/mods/DynamicTradingV1').

2. Standard Format (.txt):
   Every manual must start with:
   Title: [Summary]
   Tags: [tag1, tag2]

3. Key Commands:
   - python3 docs.py --docs [id] : View documentation.
   - python3 docs.py --verify    : Ensure all docs follow the standard and identify orphans.

4. Discovery:
   - Related Topics are suggested based on Tag overlap and embedded @slug or [path] links.
