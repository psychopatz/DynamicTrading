# Mod Docs

Use this skill when you need to understand the project architecture or look up documentation for specific files and systems. This skill saves tokens by providing summarized documentation.

## How to use it

To learn everything about this skill and to get started, run the CLI tool's help command:

```bash
python3 .agent/skills/mod-docs/scripts/docs.py --help
```

(Do not try to guess its usage, always run `--help` if you forget how to use it.)
